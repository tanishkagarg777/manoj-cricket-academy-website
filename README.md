# 🏏 Manoj Cricket Academy Website
An elegant, responsive, and modern landing page built with React.js for **Manoj Cricket Academy**. This website showcases the academy's facilities and campus to help aspiring cricketers connect and join.

---

## ✨ Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
- **Interactive Navigation:** Smooth transition between sections like Home, Campus, Why Choose Us, and Contact.
- **Dynamic UI:** Built with modern React components and custom styling.
- **Social Integration:** Fast access to academy contact details and social links.

---

## 🛠️ Technologies Used

| Technology | Purpose |
| :--- | :--- |
| **React.js** | The main framework used to build the website's pages and structure. |
| **HTML5 & CSS3** | Used to design the layout, colors, fonts, and animations. |
| **JavaScript (ES6+)** | Adds interactivity, like button clicks and smooth scrolling. |
| **Font Awesome** | rovides the icons (like icons for social media or contact info). |

### Installation & Setup
```bash
# Clone the repository
git clone [https://github.com/tanishkaagarg613/manoj-cricket-academy-website.git](https://github.com/tanishkaagarg613/manoj-cricket-academy-website.git)

# Navigate into the project directory
cd manoj-cricket-academy-website

# Install dependencies
npm install

# Start the development server
npm start

# Open http://localhost:3000 in your browser to view the application.
```
